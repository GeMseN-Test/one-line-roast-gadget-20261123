## The roast

> My phone has autocorrected my own name wrong for three years — it knows my face, my fingerprint, my location, but not how to spell me.

134 characters. One concrete scene (three years of the same mistake), one
specific detail (face / fingerprint / location), punch at the end.

## How it works

`main.py` writes that single line, deterministically, to `/output/entry.txt`
(no trailing newline). Run it twice and the SHA-256 is identical.

```sh
python3 main.py
cat /output/entry.txt
```
